---
name: testing
description: "Cuando se escriben o amplían tests y el proyecto ya tiene framework de tests: sigue `testing_basico.md`. Sin framework configurado: inicio."
---

Ejecuta la escritura de tests siguiendo `ai_docs/dev_templates/testing_basico.md`.

Aplica los pasos de la plantilla pertinentes al riesgo del cambio; declara los omitidos con su motivo.
Si el proyecto no tiene framework de tests configurado, no escribas tests: remite a `ai_docs/core_templates/04_setup_testing.md`.
Presenta los tests propuestos al usuario antes de crearlos y ejecuta para verificar que pasan.
